# Trabajo práctico 04
Alumno: Carlos Zavaleta
## Descripción
El trabajo práctico se trata de desarrollar un sistema que administre un registro de mascotas, para su venta u adopción.
Utiliza Node, Express y EJS.
Presenta un listado de registros, una pantalla de descripción y otra de alta de datos, utilizando registros iniciales de un json, pudiendo agregar datos temporalmente pero sin grabarlos.

## Instalación
Luego de descargar el repositorio y teniendo instalado node.js se instala mediante
npm install
Luego instalar las dependencias
npm install express ejs express-ejs-layouts

## Ejecución

El programa se ejecuta con npm start desde la carpeta raíz (tp-04-mascotas-ejs)
